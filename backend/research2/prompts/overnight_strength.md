# 任务目标

从9:50开始采集数据，执行一次A股“10:00买入—下一交易日10:00卖出”的隔日强势筛选，寻找下一交易日早盘可能继续大涨、触及涨停或获得较高隔夜收益的股票。

主评价目标为：10:00实际可成交均价买入；下一交易日10:00实际可成交均价卖出；计算扣除预估交易费用后的净收益。

辅助评价指标为：下一交易日10:00前是否触及买入价+5%；下一交易日全天是否触及涨停；是否出现低于买入价-3%的风险。不得把“盘中曾涨5%”“10:00收益超过5%”和“全天涨停”混为同一个成功标准。

# 交易日确认

先确认今天是否为中国大陆沪深A股正常交易日，同时核对沪深交易所交易日安排、上证指数和深证成指实时行情是否正常更新、当前是否处于正常连续竞价交易状态。如果今天不是交易日，或者市场因异常情况暂停交易，只输出：“今日不是A股正常交易日，不执行选股。”

# 数据源优先级

优先使用腾讯实时行情 `https://qt.gtimg.cn/q={code}` 和分钟行情 `https://web.ifzq.gtimg.cn/appstock/app/minute/query?code={code}`。腾讯数据缺失时，再使用东方财富全市场列表和分钟行情。腾讯代码沪市为`sh600000`、深市为`sz000001`；东方财富沪市为`1.600000`、深市为`0.000001`。如果核心行情字段无法取得，不得猜测或编造；应降低评分、剔除股票或明确写出数据缺失。

# 可交易股票池

仅选择沪深主板正常交易股票。必须剔除科创板、创业板、北交所、ST、*ST、退市整理、停牌、上市未满10个交易日、需要特别权限、10:00已经涨停跌停或无法正常成交、封单明显且大概率无法成交，以及一手100股预计含费用总成本超过12,000元的股票。

# 三层量化筛选

所有指标只能使用数据截止时间以前的数据。

市场环境满分20分：全市场上涨家数及比例5分；截止前成交额相对近5个交易日同期水平5分；上证、深证、创业板指数趋势5分；早盘涨停数量、炸板数量及炸板率5分。市场明显偏弱时提高入选门槛。

板块强度满分30分：相对沪深指数超额强度8分；板块内部上涨比例6分；至少3只同板块股票同步走强6分；9:30至截止时间成交额相对近5日同期放大程度6分；催化新鲜度和可验证程度4分。不能只因一只股票上涨就认定板块共振。

个股强度满分40分：板块内涨幅、成交额和强度排名6分；距离早盘最高价的位置5分；相对当日VWAP的位置6分；9:30至截止时间量价配合和成交放大8分；冲高后的最大回撤及修复6分；换手率、成交额、资金流和盘口流动性5分；近期过度加速或高位兑现风险4分。

催化质量满分10分。区分当天截止前新催化、前一日晚间且今日首次交易的催化、已经交易多个交易日的旧消息、无法核实的传闻。旧公告只能作为背景，不得事后拼接为今日上涨原因。

# 风险扣分

在100分基础评分后扣除0—25分：减持、解禁、监管问询、立案调查；业绩大降或不及预期；高开低走且无法修复；连续大涨且过热；板块前排大面积涨停而候选为后排；放量滞涨；催化无法核验或依赖传闻；流动性不足或价差异常；其他下一交易日集中兑现风险。

最终分 = 市场分 + 板块分 + 个股分 + 催化分 - 风险扣分。最终分只是规则匹配分，不是涨停概率。

# 入库与执行规则

`recommendations`是程序入库清单，不代表报告文字中的主观推荐态度。结构化候选的最终分只要超过50，就必须放入`recommendations`，不得因为结论写了“空仓”“不推荐”“谨慎”或类似表述而省略或否决。最终分不超过50的候选不得放入。最多保留最终分最高的3只。

每只入库候选都要给出买入下限和上限；超过上限不追高；显著跌破下限视为信号失效；10:00涨停、封死或不可成交则取消执行；板块或指数突发跳水则取消执行。取消执行只影响交易，不改变已经按最终分完成的入库判定。

# 报告格式

第一部分先给可执行结论：是否交易日、推荐数量、可执行标的、数据截止时间、报告生成时间、是否在时限内送达。

可执行标的表包含排名、代码、名称、最终分、参考价、买入区间、100股预计成本、市场/板块/个股/催化分、风险扣分。每只股票补充入选理由、关键量化数据、当天新催化、旧消息背景、主要风险和取消条件。

市场与板块分析列出上涨家数和比例、截止前市场成交额、早盘炸板率、三大指数趋势、板块相对强度、板块上涨比例、同步走强股票数和成交放大倍数。
