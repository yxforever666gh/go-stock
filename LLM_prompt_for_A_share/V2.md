执行一次A股隔夜强势筛选。所有时间均为北京时间。

# 一、策略目标

本任务在每个A股交易日09:45启动，寻找在09:55后能够按最新实时价格实际买入、并按下一交易日10:00时间戳分钟线收盘价卖出时，风险收益比较好的沪深主板股票。

核心评价目标是“实际可成交信号价至下一交易日10:00的收益”，不是预测当天盘中涨停，也不是单纯寻找当前涨幅最大的股票。不得把“当下很强”“盘中曾上涨5%”“下一交易日10:00有正收益”和“全天涨停”混为同一成功标准。

第一优先级是按时给出可执行结论；不允许为了补充非关键数据、搜索大量新闻或制作复杂报告而错过交易窗口。

# 二、交易日和时间规则

1. 先确认今天是否为中国大陆沪深A股正常交易日，并核对指数行情是否正常更新、市场是否处于连续竞价。
2. 若不是正常交易日，只输出“今日不是A股正常交易日，不执行选股”，不创建CSV。
3. 09:45—09:54完成全市场初筛和候选排序。
4. 09:55后对候选Top 3重新获取一次腾讯实时报价；报告无论何时完成，都必须再次获取送达前的最新实时报价，并以该价格作为唯一signal_price。
5. 不设置10:05自动取消规则。只要最新价格仍在买入区间、股票可正常成交且其余条件达标，就可以正式推荐；不得使用已经失效的历史价格追认成交。
6. 默认下一交易日10:00卖出。统一使用腾讯分钟行情中时间戳为10:00的分钟线收盘价（该分钟最后成交价）作为sell_price。若10:00分钟数据缺失，则使用10:00之后第一笔可成交价，并在data_note说明。不得使用盘中最高价或其他事后更有利的价格。

# 三、股票范围和资金约束

仅筛选沪深主板普通A股：

- 上交所600、601、603、605开头；
- 深交所000、001、002、003开头；
- 排除创业板、科创板、北交所、B股；
- 排除ST、*ST、退市整理、停牌、上市未满10个交易日及需要特别权限的股票；
- 排除当前涨停、跌停、封单导致无法正常成交、流动性明显不足的股票；
- 账户可用资金总额上限12,000元，按100股一手并预留必要买入费用，单只股票的lot_cost不得超过12,000元；
- 所有正式推荐股票均按至少买入100股计算，全部status=formal记录的lot_cost合计不得超过12,000元；若超出，按value_score、final_score和可成交性排序依次保留，直到总成本符合限制；
- 每天最多正式推荐3只，允许0—3只，禁止为了凑数降低标准。

# 四、Diemeng作为证券主表和历史分钟数据源。

不得用涨幅榜前100名冒充全市场数据。全市场接口或板块数据覆盖不完整时，必须明确标注缺失，不能据此虚构全市场上涨比例、炸板率、板块宽度或成交放大倍数。核心行情字段无法取得的股票不得正式推荐。

新闻和催化优先核验公司公告、交易所公告及权威财经媒体。只对候选Top 3核验催化，不对大量初筛股票逐一搜索新闻。昨天或更早已被市场交易的消息只能作为背景，不得重复按新催化加分。

# 五、候选生成

不得只从涨幅最高的股票中选股。初筛应重点覆盖：

- 当日涨幅约2%—7%、尚未明显透支的股票；
- 强势板块中处于前排、但仍可正常成交的股票；
- 板块趋势延续、个股相对位置合理、没有明显冲高回落的股票；
- 有持续资金承接、但没有明显偏离当日VWAP的股票。

涨停股只能用于判断板块强度，不能作为正式或影子推荐。若板块前排已大面积涨停、剩余可买股票明显属于后排，应降低评分或放弃该方向。

# 六、双评分体系

每只候选分别计算两个0—100分的分数。分数是规则匹配度，不是涨停概率或盈利概率。

## 1. 强势持续分S

- 市场环境：15分；
- 板块共振、板块宽度和趋势持续性：35分；
- 个股相对强度、板块地位和量价结构：40分；
- 今日首次交易且可验证的新催化：10分。

没有新公告不能直接否定股票。若板块趋势和资金共振充分，仍可获得较高持续分。旧消息和无法核实的传闻不得作为新催化加分。

## 2. 买入性价比分V

- 相对合理目标的剩余上涨空间：30分；
- 非过热程度、VWAP偏离和连续加速风险：30分；
- 分时承接、回撤修复和尾段量价结构：20分；
- 流动性、资金容量和实际可成交性：10分；
- 财务、公告、减持、监管及隔夜事件风险：10分。

V分越高表示当前价格越值得买入。不得把“涨得多、接近最高价、接近涨停”直接视为高性价比。

## 3. 最终分

final_score = 0.45 × strong_score + 0.55 × value_score

结果四舍五入为整数。

# 七、过热与风险约束

以下因素必须降低value_score；同一风险只扣一次，避免重复惩罚：

- 当前涨幅5%—7%：扣5分；
- 当前涨幅7%—8.5%：扣10分；
- 当前涨幅超过8.5%：扣15分；
- 距离涨停不足3%：再扣8分；
- 高于当日VWAP 3%—5%：扣5分；
- 高于VWAP超过5%：扣10分；
- 最近3个交易日累计涨幅超过15%：扣5分；超过25%：扣10分；
- 连续两日以上加速、缩量冲高、高开后承接不足：扣5—10分；
- 板块前排大面积涨停、候选明显属于后排：扣10分；
- 减持、解禁、问询、立案、业绩不及预期、异常放量滞涨、流动性不足或隔夜事件风险：按严重程度扣分或直接剔除。

不得因为“公司刚发布利好”“位于早盘最高价附近”或“当前涨幅很大”而自动给高分。

# 八、正式推荐条件

只有同时满足以下全部条件才可正式推荐：

- strong_score不低于60；
- value_score不低于65；
- final_score不低于65；
- 最新signal_price仍在给出的buy_low与buy_high之间；
- 当前可正常成交；
- 不存在严重过热、明显冲高回落、重大风险或核心数据缺失；
- 与其他候选相比具有明确优势。

若多只达标，按value_score、过热程度和final_score综合排序，最多正式推荐3只；不得简单按当前涨幅排序。

若没有完全达标的股票，明确输出“正式推荐：0只，今日建议空仓”。65—74分的股票可以正式推荐，但必须同时满足两个子分门槛；75分以上也不得自动推荐。

# 九、市场极弱关卡

若下列情况出现两项，原则上不正式推荐：

- 有效全市场上涨比例低于30%；
- 上证、深成指、创业板中至少两个从开盘后持续走弱；
- 可验证的主板炸板率超过25%；
- 成交放大但指数和上涨家数同步转弱；
- 最强板块只有涨停前排上涨、可成交后排普遍回落。

只有存在明确独立行情、板块宽度充分且value_score达到75以上时，才允许例外推荐。

# 十、成交和统一复盘口径

正式推荐必须基于报告送达前最后一次取得的实时价格，并给出：

- signal_price；
- buy_low和buy_high；
- 100股预计成本lot_cost；
- 超过buy_high不追高；
- 跌破什么价格或出现什么市场条件时取消；
- 下一交易日按10:00时间戳分钟线收盘价卖出。

统一复盘口径：

- 正式标的和影子候选均使用当日报告完成前同一轮最新行情价格作为signal_price；
- sell_price固定使用下一交易日腾讯分钟行情中时间戳为10:00的分钟线收盘价（该分钟最后成交价）；若该数据缺失，使用10:00之后第一笔可成交价并在data_note说明；
- return_pct=(sell_price/signal_price-1)×100，未扣费用；
- 不得使用盘中最高价或事后更有利的价格；
- 因超价或触发取消条件的标的不计入正式收益；
- formal、shadow、cancelled和no_trade必须分别保留，不能混合统计；
- 如果无法可靠取得原始信号记录，不补造review数据。

# 十一、时效优先和CSV输出

先完成交易结论，再生成一个极简CSV。不得生成Excel、Markdown长报告、Word、PDF、图片、图表或其他文件；不得进行排版、渲染、预览或复杂格式校验。

非关键数据无法及时取得时直接留空，并在data_note说明；禁止为了补齐非关键数据延迟结论。

CSV文件名：

a_stock_signal_YYYY-MM-DD.csv

CSV规范：

- UTF-8 with BOM编码；
- 英文逗号分隔，第一行为固定字段名；
- 数字字段只写数字，不带“元”“分”“%”；
- return_pct以百分数数值保存，例如2.35%写2.35；
- 缺失字段留空，不填写“未知”“无”或“-”；
- 含逗号、双引号或换行的文本按标准CSV转义；
- 只创建并写入一次CSV。

固定字段，禁止增加：

record_type,task_date,signal_date,signal_time,report_time,status,rank,code,name,signal_price,buy_low,buy_high,lot_cost,strong_score,value_score,final_score,sell_date,sell_time,sell_price,return_pct,main_reason,cancel_condition,data_source,data_note

字段定义：

- record_type：signal或review；
- 日期格式：YYYY-MM-DD；时间格式：HH:MM；
- status：formal、shadow、cancelled或no_trade；
- rank：候选排名，从1开始；
- code：6位代码，不加交易所前缀；
- signal_price：报告送达前最后一次实时报价；
- lot_cost：100股加预估买入费用；
- sell_time：计划或实际统一为10:00；
- main_reason：最多40个汉字；
- cancel_condition：最多40个汉字；
- data_source：Tencent、Eastmoney或Tencent+Eastmoney；
- data_note：只记录数据缺失、接口异常、超价等异常，最多40个汉字。

今日signal记录：

- 正式推荐最多3行，status=formal；
- 在正式推荐之外，额外保留最多3只高分候选；从未正式入选但评分最高、数据完整且有观察价值的股票中选取，不得为了凑数补足3只；
- 高分候选未触发取消条件时写status=shadow；超价或触发取消条件时写status=cancelled。shadow与cancelled合计最多3行，且不占用正式推荐的3行名额；
- 若无正式推荐，必须额外写1行status=no_trade，code和name留空，main_reason写空仓主因；
- 今日signal候选记录最多6行：正式推荐最多3行，高分候选最多3行；无正式推荐时另加1行no_trade，不凑满。

上一交易日review属于次要步骤，只能在今日结论已确定后执行：

- 若可直接取得上一交易日原始正式推荐及高分候选记录，则最多追加6行record_type=review：formal最多3行，shadow或cancelled合计最多3行；
- 沿用原signal_date、signal_time、signal_price和原status；
- sell_price固定使用今日腾讯分钟行情中时间戳为10:00的分钟线收盘价；若该数据缺失，使用10:00之后第一笔可成交价并在data_note说明，再按统一公式计算return_pct；
- 若原记录无法立即取得，直接跳过，不搜索或补造，不得延误今日信号。
