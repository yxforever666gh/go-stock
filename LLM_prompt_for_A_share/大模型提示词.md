# 任务目标

time1 = 9:50

执行一次A股“time1买入—下一交易日10:00卖出”的隔日强势筛选，寻找下一交易日早盘可能继续大涨、触及涨停或获得较高隔夜收益的股票。

主评价目标为：

- time1实际可成交均价买入；
- 下一交易日time1实际可成交均价卖出；
- 计算扣除预估交易费用后的净收益。

辅助评价指标为：

- 下一交易日time1前是否触及买入价+5%；
- 下一交易日全天是否触及涨停；
- 是否出现低于买入价-3%的风险。

不得把“盘中曾涨5%”“time1收益超过5%”和“全天涨停”混为同一个成功标准。

# 交易日确认

先确认今天是否为中国大陆沪深A股正常交易日。

同时核对：

1. 沪深交易所交易日安排；
2. 上证指数、深证成指实时行情是否正常更新；
3. 当前是否处于正常连续竞价交易状态。

如果今天不是交易日，或者市场因异常情况暂停交易，只输出：

“今日不是A股正常交易日，不执行选股。”

如果核心行情字段无法取得，不得猜测或编造。应降低评分、剔除该股票，或明确写出数据缺失。

# 可交易股票池

默认按普通A股账户处理，仅选择沪深主板正常交易股票。

必须剔除：

- 科创板、创业板、北交所；
- ST、\*ST、退市整理股票；
- 停牌股票；
- 上市未满10个交易日的股票；
- 需要特别交易权限的股票；
- time1时已经涨停、跌停或无法正常成交的股票；
- 封单明显、正常委托大概率无法成交的股票；
- 一手100股预计总成本超过12,000元的股票。

账户资金上限为12,000元。计算一手成本时应预留佣金、过户费等交易费用，不得只使用“股价×100”。

# 三层量化筛选

按照“市场—板块—个股”进行筛选。所有指标只能使用time1以前的数据。

## 第一层：市场环境，满分20分

1. 全市场上涨家数及上涨比例：5分；
2. time1前成交额相对近5个交易日同期水平：5分；
3. 上证、深证、创业板指数time1趋势：5分；
4. 早盘涨停数量、炸板数量及炸板率：5分。

市场环境明显偏弱时，提高个股入选门槛，不得因为个股分时强势就忽略系统性风险。

## 第二层：板块强度，满分30分

1. 板块相对沪深指数的超额强度：8分；
2. 板块内部上涨比例：6分；
3. 至少3只同板块股票同步走强：6分；
4. 板块9:30—time1成交额相对近5日同期放大程度：6分；
5. 板块催化的新鲜度和可验证程度：4分。

不能只因为一只股票上涨，就认定整个板块形成共振。

## 第三层：个股强度，满分40分

1. 个股在板块内的涨幅、成交额和强度排名：6分；
2. 当前价距离早盘最高价的位置：5分；
3. 当前价相对当日VWAP的位置：6分；
4. 9:30—time1量价配合和成交放大程度：8分；
5. 开盘冲高后的最大回撤及修复能力：6分；
6. 换手率、成交额、资金流和盘口流动性：5分；
7. 近期走势是否过度加速或存在高位兑现风险：4分。

## 催化质量，满分10分

公司公告和新闻必须区分：

- 当天time1前出现的新催化；
- 前一日晚间出现、今日首次交易的催化；
- 已经交易多个交易日的旧消息；
- 无法核实的市场传闻。

当天新催化可以正常计分；前一日晚间首次交易的催化可以计分；已经交易十几天的旧公告最多只能作为基本面背景，不能作为今日上涨原因重复计分。

不得为了给上涨找理由而事后拼接旧消息。

# 风险扣分

在100分基础评分后，按下列风险扣除0—25分：

- 减持、解禁、监管问询、立案调查；
- 业绩大幅下降或业绩不及预期；
- 高开低走、开盘冲高后无法修复；
- 近期连续大涨、技术位置明显过热；
- 板块前排已经大面积涨停，候选股属于明显后排；
- 成交突然异常放大但价格停滞；
- 催化无法核验或主要依赖传闻；
- 流动性不足、买卖价差异常；
- 其他可能造成下一交易日集中兑现的风险。

最终分计算方式：

```text
最终分 = 市场分 + 板块分 + 个股分 + 催化分 - 风险扣分
```

最终分只是“规则匹配分”，不是涨停概率，也不能写成“有84%的概率涨停”。

# 入选规则

推荐必须同时满足：

- 分数需要超过50；
- time1时可以正常成交，没有涨停。

最多展示3只可执行标的股票。

每只股票必须给出：

- 建议买入下限；
- 建议买入上限；
- 超过上限时“不追高”；
- 跌破下限较多时，判断早盘信号可能失效并取消交易；
- 如果time1时已经涨停、盘口封死或无法正常成交，取消推荐；然后换一只股票分析、推荐；
- 如果板块或指数在time1突发明显跳水，取消交易；然后换一只股票分析、推荐。

# 报告格式

报告第一部分必须先给出可执行结论，不要把推荐结果放在长篇分析之后。

## 今日结论

- 今日是否为交易日；
- 推荐数量；
- 可执行标的；
- 数据截止时间；
- 报告生成时间；
- 是否在可执行时限内送达。

## 可执行标的

| 排名 | 代码 | 名称 | 最终分 | time1参考价 | 建议买入区间 | 100股预计成本 | 市场/板块/个股/催化 | 风险扣分 |

每只股票补充：

- 入选理由；
- 关键量化数据；
- 当天新催化；
- 旧消息背景；
- 主要风险；
- time1取消交易条件。

## 市场与板块分析

列出：

- 上涨家数和上涨比例；
- time1前市场成交额；
- 早盘炸板率；
- 三大指数9:30—time1趋势；
- 入选板块相对强度；
- 板块上涨比例；
- 同步走强股票数量；
- 板块成交放大倍数。
