# go-stock

![go-stock social preview](./docs/assets/social-preview.png)

## 当前版本：App 2.4.0

Go-Stock 是基于 Go、Vue 3、Naive UI 和 SQLite 的本地股票行情与 AI 研究工具。本版本增加受控知识库、人工审批的长期记忆候选与可审计的研究检索。

[Releases](https://github.com/yxforever666gh/go-stock/releases) | [发布说明](./RELEASE_NOTES.md)

> 本仓库基于公开项目 [`ArvinLovegood/go-stock`](https://github.com/ArvinLovegood/go-stock) 演化，不是原作者官方仓库。

## 2.4 核心流程

1. 在沪深交易日的 `09:30、11:30、14:30` 自动启动分级分析；时间和 AI 配置可在设置页调整。程序启动会补跑最近一个错过的节点，失败后每 5 分钟重试至当日收盘。
2. AI 依次完成大盘、板块、个股和最终决策分析，整合现有新闻、研报、公告、资金流、宏观、财务、概念、实时行情与 K 线数据。
3. 每轮允许空仓，并可从现有最多 15 只 shortlist 中推荐任意数量的可交易沪深 A 股；涨跌停、停牌、北交所和批次内重复候选会在入库前由代码过滤。
4. AI 推荐按最新可交易行情直接模拟买入；非交易时段完成的推荐顺延至下一有效交易时段并只尝试一次。持仓首轮从配置时间开始，之后按每只股票的实际复查完成时间独立计时，失败同样每 5 分钟重试至当日收盘。
5. 买入后的下一交易日从 09:50 起按固定 15 分钟时点复查实时行情、分钟量价和增量事件，由 AI 判断“持有 / 卖出”；停牌或跌停时进入待卖状态。
6. 研究中心1展示原 AI 分析、推荐、收益和完整判断时间线；研究中心2独立执行 09:50—次交易日10:00 的隔夜强势策略。

研究中心2固定在交易日 09:50 开始采集、09:55 冻结证据，报告尽量在 09:55—10:00 输出；10:00 模拟买入，下一交易日 10:00 模拟卖出。其 12,000 元账户、推荐、成交与收益完全独立，实际可买标的按 1—3 只等额分配现金并以 100 股整手向下取整。

旧策略、cohort、冻结回放、runtime guard、preflight、策略审计、旧收益重算和 AI 智能体均已退出运行链路。1.6.6 将旧策略表永久压缩归档后移出活动库，运行链不再读取或写入这些历史数据。

2.0.0 新增的证据链能力默认关闭，不改变既有自动研究与模拟交易语义。证据可用时间使用 `available_at` 作为截止判定依据，采集时间 `collected_at` 只用于审计；多资产缓存只为后续行情扩展提供数据基础。

2.1.0 将每个作用域、资产、周期和复权组合的当前绘图文档独立保存，并为每次变更追加不可覆盖的修订记录；删除采用可审计的软删除时间，不改写既有研究、账户、推荐、成交或收益数据。

2.2.0 将每日炒作题材固定为“观察 → 发酵 → 加速 → 分歧 → 退潮”五阶段，按交易日冻结题材排名、热度、成分股与催化剂。相同事件和相同来源链接会去重，不同来源的支持、反驳和中立主张并列保留；证据关联继续以可用时间支持研究截止过滤。

题材采集在沪深交易日 15:10 运行，热门话题、热点事件、新闻电报和概念资金流按来源独立降级；公开页面可直接查看。题材及催化只有在默认关闭的实验证据模式开启后才进入 Research 1、Research 2，并继续服从各自的研究截止时间；ETF 与基金成分始终不进入荐股候选或模拟交易。

2.3.0 为两套研究增加不可覆盖的 Prompt 模板版本和逐次模型调用载荷归档。最终 Prompt、证据、工具清单、原始响应、可选修复响应及修复日志均按 gzip BLOB 与 SHA256 保存；运行状态只允许更新进度字段，已存载荷禁止修改或删除。研究回放固定来源运行、模型配置与截止时间，结果同样不可覆盖，且不会回填旧运行或改变原研究、推荐与模拟交易历史。

2.4.0 支持导入 TXT、Markdown 和可提取文本的 PDF，也可把既有 Research 1/2 报告保存为知识草稿。文档内容采用不可覆盖版本，只有用户明确批准且未被后续版本替代的内容才能通过 FTS5 进入研究检索；AI 生成的长期记忆始终先进入候选队列，不能自行批准。所有知识文本都按不可信外部线索处理，内含指令不能覆盖研究规则，引用事实仍须用本次截止时间前的市场证据复核；每次检索命中、采用或拒绝原因均保留审计记录。

统一图表支持沪深股票、指数和场内 ETF 的 `1/5/15/30/60` 分钟、日、周、月、季、年周期，以及 `none/qfq/hfq` 复权；ETF 默认不复权，指数只允许不复权。前端提供 MA、BOLL、VOL、MACD、KDJ、RSI 和测距、趋势线、射线、水平线、波段、斐波那契回撤。港美行情继续使用旧数据接口，但转换到同一渲染核心；研究复盘继续保留真实成交、分钟净盈亏、数据缺口与来源错误。

## 模拟账户与净收益

- 初始资金：固定 `500,000 元`，不再计划或执行追加注资
- 不限制持仓总数或重复股票；每个推荐按独立仓位核算，待买任务仍按候选行情、最小整手和费用预留资金
- 单只股票现金支出目标：`50,000 元`；选择实际支出首次严格超过目标的最小整手。若目标仓位现金不足，则回退为可承担的最大整手；连一手也无法承担才跳过
- 普通沪深 A 股：100 股整数倍；科创板首次申报至少 200 股
- 成本：佣金、最低佣金、卖出印花税、过户费和双边滑点
- 净收益额：`现金 + 持仓按可卖出净值估值 - 500,000 元固定初始资金`
- 策略净收益率：使用固定本金口径的单位净值与时间加权收益率（TWR）

已平仓交易采用实际净现金流；未平仓持仓按最新价扣除预计卖出成本估值。1.7.x 不计算或展示基准收益率、超额收益率和 XIRR。

## 界面结构

- 市场行情：保留快讯、指数、行业排名、资金流、龙虎榜、公告、研报、热点、选股与名站信息；热点页增加“每日炒作题材”视图，展示题材阶段、冻结快照、成分股与催化来源冲突。
- 研究中心1：保留原研究页签并增加 `知识库与记忆` 管理入口，可导入、检索、审批文档版本和记忆候选。
- 研究中心2：提供独立的 `AI分析报告`、`股票推荐记录`、`股票收益率` 和 `设置` 页签；设置页显示隔夜强势自动策略开关及研究中心2专属报告邮件配置。
- 设置：不再单独占用侧边栏入口；通用设置、数据接口和模型配置继续共享，两个中心的策略控制项互不串页。
- AI 分析：自动开关只控制定时触发，研究中心手动分析始终调用同一分析后端和同一组模型；持仓复查的开始时间与间隔可配置。

## AI 配置

AI 模型配置表从上到下即为回退顺序，关闭的模型会被跳过。研究调用采用流式接收：连续 300 秒没有有效推理、心跳、状态或正文事件才超时，活跃推理不限制总时长。瞬态错误在当前模型最多尝试 5 次，不可恢复错误立即切换下一模型。API Key 仍由用户在本机设置，迁移不会复制或生成密钥。

Responses API 优先使用 `previous_response_id` 延续单股会话；中转站不支持续接时，只重发该股票本地保存并压缩后的历史消息。

## 数据库

- 主库 schema：`19`
- 分钟库 schema：`3`
- 1.6.x 表统一使用 `research_v160_` 前缀

schema 3 创建分析运行、推荐、生命周期消息、AI 决策事件、模拟账户、交易和持仓表；schema 4 增加逐模型启用状态；schema 5 增加脱敏的模型调用诊断记录；schema 7 增加生命周期证据快照；schema 8 将旧待激活记录迁移到一次性直接买入流程；schema 9 在永久归档后删除 1.5 旧策略表；schema 10 增加分期入金、资金预留、单位净值与策略评估快照；schema 11 增加分钟线接口顺序和持仓复查时间配置；schema 12 将研究中心1账户追溯重置为固定 50 万元；schema 13 新增研究中心2的独立 12,000 元账户、报告、推荐、成交、指标和自动开关；schema 14 增加研究中心2专属 SMTP 配置和持久化邮件投递队列；schema 15 增加冻结证据集、证据项、两套分析运行的可空版本关联和默认关闭的实验开关；schema 16 增加按作用域、资产、周期和复权隔离的当前绘图文档，以及不可覆盖的绘图修订历史；schema 17 增加归一化题材、别名、不可覆盖每日快照、催化事件、不可覆盖来源主张、冻结成分股和证据关联；schema 18 增加不可变 Prompt 版本、完整模型调用载荷、运行审计状态、受控回放及不可变回放结果；schema 19 增加不可变知识版本、人工审批状态、FTS5 索引、记忆候选与检索审计。schema 15—19 均不回填或重写历史研究、账户、推荐及交易数据。分钟库保持 schema 3，2.4.0 不升级分钟库。

## 本地运行

要求 Go 1.25+、Node.js 20+。

```powershell
cd frontend
npm install
npm run build
cd ..
go run .
```

默认监听 `http://127.0.0.1:34115`，可用 `--web-addr` 修改监听地址。

已部署的 Windows 发布物可直接双击 `启动项目.cmd`；如只需启动服务、不打开浏览器，可运行：

```powershell
.\启动项目.cmd -NoBrowser
```

网络来源审计已从主程序移到独立开发工具，需要时运行：

```powershell
.\scripts\network-audit.ps1
```
