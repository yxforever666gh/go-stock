## 🐛 原始问题

问题描述: 项目每隔一段时间自动崩溃，无法登录访问

根本原因:
  ❌ Goroutine 死锁 (backend/data/ai_recommend_yield_overview.go:419)
  ❌ 端口占用未清理 (34115)
  ❌ 无自动恢复机制

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## ✅ 修复方案

### 1. 代码修复
文件: backend/data/ai_recommend_yield_overview.go
修改: 为 semaphore 获取添加 30 秒超时保护

修改前:
  sem <- struct{}{}  // 会永久阻塞
  defer func() { <-sem }()

修改后:
  select {
  case sem <- struct{}{}:
      defer func() { <-sem }()
  case <-time.After(30 * time.Second):
      // 超时返回，避免死锁
      return
  }

### 2. 监控脚本
文件: scripts/restart.sh
功能:
  ✓ 健康检查 (每 60 秒)
  ✓ 自动重启 (连续失败 3 次)
  ✓ 端口清理
  ✓ 崩溃日志记录

### 3. Systemd 服务
文件: scripts/go-stock-monitor.service
功能:
  ✓ 开机自启动
  ✓ 崩溃自动恢复
  ✓ 资源限制保护

## 🚀 部署建议

### 推荐: 使用 systemd (生产环境)

1. 安装服务:
   sudo cp scripts/go-stock-monitor.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable go-stock-monitor
   sudo systemctl start go-stock-monitor

2. 查看状态:
   sudo systemctl status go-stock-monitor
   tail -f logs/monitor.log

### 备选: 手动启动

   bash scripts/restart.sh start
