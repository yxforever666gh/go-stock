# 选股策略：开盘涨幅前三

版本：2026-09-14。用途：选股观察与历史复核，不自动下单。

## 一、当前采用的规则

**每天09:30开盘报价公布后，在当天尚未触板的合格股票中，按开盘涨幅从高到低选3只。**

这是目前本地研究中表现最好的基准。前20只重排、复杂模型和分批选股尚未证明能进一步提高命中率。

### 1. 股票范围

- 普通10%涨跌幅限制的沪深主板股票，排除当日ST、退市整理及不适用普通涨跌幅规则的特殊交易日。
- 研究代码范围为：沪市600、601、603、605；深市000、001、002、003开头。代码前缀仅用于缩小范围，不能代替当日交易状态核验。
- 昨日是否涨停不作为排除条件。
- 开盘报价、当日参考前收盘价、当日涨停价必须有效；09:30对应开盘记录须有成交量。
- 历史资料无法核验时，单独列为价格情景研究，不混称正式涨停结果。

### 2. 信息时点与触板排除

- 使用09:30已经公布的开盘报价，不声称在09:25或开盘前知道最终开盘价。
- 开盘价必须低于当日涨停价；截至观察时刻的最高价也必须低于涨停价。
- 已在开盘触板或一字涨停的股票不进入当天新选名单。
- 如果实际取得数据晚于09:30，必须记录实际时间，并检查此时是否已经触板。不能把延迟得到的信息冒充09:30信号；这种延迟执行也不直接沿用原研究命中率。

### 3. 排序与数量

计算：

```text
开盘涨幅 = (09:30开盘价 / 当日参考前收盘价 - 1) × 100%
```

当日参考前收盘价和涨停价优先使用可靠数据源提供的当日字段。无法核验时，不随意用其他价格替代后仍标作同一口径。

1. 按未截断的开盘涨幅降序排列。
2. 涨幅相同，按六位股票代码升序；完全相同代码再按交易所排序。
3. 保留前20只作为观察与审计清单，**正式名单直接取其中前3只**。
4. 同一天同一股票只出现一次。选定后不按后续表现换股或删除。
5. 不额外设置“必须高开7%”“前日必须放量”等硬条件，也不使用旧树的5.67%分档代替连续排序。
6. 合格股票不足3只时，列出实际数量和原因；不得用已触板、停牌或缺数据股票凑数。

## 二、每日输出

正式3只及前20观察池均保留：

| 字段 | 内容 |
|---|---|
| 日期、时刻 | 交易日、报价时间和实际选出时间 |
| 排名、股票 | 名次、六位代码、交易所；有可靠名称时附名称 |
| 开盘价、参考前收盘价 | 排序使用的原始价格字段 |
| 当日涨停价 | 用于检查是否已经触板 |
| 开盘涨幅 | 展示可保留两位小数，但排序使用完整精度 |
| 资格与来源 | 当日交易状态、触板检查、数据来源及缺失说明 |

前日振幅、相对成交量、近期涨停次数可以附作观察说明，**目前不据此改变正式排序**。

## 三、怎样复核命中率

- T为选出日，T+1为日历中的下一市场交易日，不跳到该股票下一次有报价的日期。
- T或T+1至少一天收盘封住涨停，算一次命中；两天都封住仍只算一次。
- 仅盘中触板、收盘未封住，不算该日命中。
- 两天都已知未封板才判失败；只要一天已知封板即可判命中；其余保留未知。
- 未知结果不能记成失败，也不能从原名单删除。报告总选择数、已知命中、失败、未知及命中率上下界。
- 命中率按选出次数计算；同一股票在不同交易日再次入选，属于不同预测。另报每天命中0、1、2、3只的天数。

## 四、已有证据与边界

| 期间 | 实际交易日 | 每日数量 | 已知结果命中率 |
|---|---:|---:|---:|
| 2025-11-03至12-29验证期 | 41 | 3只 | 58.54%（72/123） |
| 2026-01-05至09-10复核期 | 168 | 3只 | 65.21%（328/503；另1次未知） |
| 2025-01-02至06-30近似回看 | 117 | 3只 | 56.13%（197/351） |

2025上半年缺少完整历史ST及当日规则核验，属于10%价位近似回看；固定模型研究也使用了其后的训练资料，不能把该阶段称为前向未见验证。2026已被多轮研究过，属于跨期复核，不是完全未触碰的最终测试。

**该策略主要筛选已经大幅高开的股票。** 2026选出时涨幅中位数为9.05%，上半年近似回看为8.92%。高命中率不代表很早识别启动，也不代表可以买到、能够盈利或未来维持同样比例。历史总体命中率不能直接当成名单中每只股票的个人概率。

本地研究使用经事后日数据质量审计的股票池，尚未认证完整退市历史与实时全市场可用性。实际使用只能依赖当时可见资料，不能把收盘后的质量或表现信息倒用作开盘筛选。

## 五、可直接使用的提示词

> 请使用本地数据执行“开盘涨幅前三”选股观察。于09:30开盘报价公布后，从当日普通10%主板非ST、交易状态和价格字段可核验、开盘有成交且截至观察时刻尚未触板的股票中，按精确开盘涨幅降序排名；同分按六位代码、交易所升序。列出前20观察池，正式选前3只，每日不重复且不事后换股。附报价时间、实际选出时间、开盘价、参考前收盘价、涨停价、涨幅与来源。没有当前数据就明确说明，不拿旧报价冒充今天，不自动下单。历史复核以T或下一市场日T+1至少一天收盘封板为命中，失败和未知均保留。不计算收益或卖点，不增加未经验证的硬筛选条件。
